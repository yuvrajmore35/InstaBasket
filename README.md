# 🛒 Smart Trolley System

## 📌 Project Overview
The Smart Trolley System is an automated retail solution designed to reduce billing time, eliminate long queues, and enhance the shopping experience in supermarkets.

This system allows customers to scan products directly in the trolley, view their bill in real-time, and complete payment without standing in billing queues.

---

## 🎯 Problem Statement
- Long waiting time at billing counters
- Manual barcode scanning causes human errors
- No real-time price tracking for customers
- Inefficient inventory management
- Poor shopping experience in crowded stores

---

## 🚀 Proposed Solution
The Smart Trolley System provides:
- Automated product scanning using RFID
- Real-time cart and bill display
- Integrated payment system (UPI & Cash)
- Product location guidance inside the store
- Secure data storage using Firebase
- Fraud detection using duplicate item detection

---

## ⚙️ Features
- 🔐 Customer and Admin Login (using MART-ID)
- 📍 Product location guidance with store map
- 📡 RFID-based product detection
- 🧾 Real-time cart display with price updates
- 💳 Digital (UPI) and Cash payment support
- ⚡ Automated billing system
- 🚫 Duplicate item detection
- 📊 Shopping analytics for store management

---

## 🧠 System Architecture
The system consists of:
- Smart Trolley Hardware (RFID Scanner,Display)
- Backend Server / Firebase Database
- Admin Portal for monitoring
- Payment Gateway Integration

---

## 🔄 Workflow
1. Customer logs in using MART-ID
2. Customer scans product using RFID module
3. Product is added to cart and displayed on screen
4. System shows real-time total bill
5. Customer completes payment (UPI or Cash)
6. Admin system updates inventory and records transaction
